# dsh-model-picker-control（模型选择器总控）

统一管理 DSH 模型选择器与 `/model` 弹窗的显示，不修改任何第三方插件。

- 重命名模型显示名与 provider 分组名。
- 调整 provider 分组顺序，隐藏整个 provider 或单个模型。
- 自定义分区（如「免费」「实验」），可把不同 provider 的模型合并到同一组。
- 组内按目录原序、或名称排序。
- 每个模型可加一个后缀胶囊（短文本，最多 20 个字符，蓝 / 暗红 / 青三色），与宿主自带的 `1017` 标签并排显示。
- 所有设置保存在 profile 配置中，重启后保留。

## 安装

```
dsh plugin add dsh-model-picker-control
```

重启 DSH，在「设置」中与「模型」页并列的 **模型选择器** 里管理。

## 说明

- 通过以优先级 `-1` 注册 `conversation.input.model` 接管选择器座位（宿主为 `0`）。选中/切换、推理档位、搜索、键盘导航、pending 状态与子会话不可用均按宿主实现移植，文案复用宿主 `model` 词条。停用本插件即还原宿主选择器。
- `/model` 弹窗使用同一套数据管线，名称、分组、顺序、隐藏与选择器一致；行 id 仍为 `provider/model`，实际切换仍由宿主处理。
- 隐藏只影响显示；已保存的选择不会被改动，触发器会显示「请选择模型」，可另选可用模型。
- 设置通过宿主 settings 服务写入本插件配置行（`config.picker`）：带版本校验、失败回滚，不会整篇重写 `cordis.patch.yml`。「全部恢复默认」可清除。
